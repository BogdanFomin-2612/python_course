JSON - Это текстовый формат обмена данными.
Применяется в веб-приложениях как для обмена
данными между клиентом (фронт или моб.прил.)
и сервером, так и между серверами.

JSON расшифровуется как JavaScript Object Notation.
Несмотря на происхождение от JavaScript, формат 
считается независимым от языка и может
использоваться практически с любым языком прогр.
